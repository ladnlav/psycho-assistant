# Демо-сценарии

Каждый файл `*.yaml` — один вымышленный пациент демо-врача с историей по неделям. Клиническое содержание сценариев проверяет врач.

```bash
docker compose exec backend python -m app.seed          # сначала демо-врач
docker compose exec backend python -m app.scenarios     # все сценарии; уже загруженные пропускаются
docker compose exec backend python -m app.scenarios s1 --reset   # перезагрузить один сценарий
```

Пароль пациентов сценариев — `SEED_PASSWORD` из `.env`. Даты считаются от сегодняшнего дня: последняя неделя заканчивается вчера, сегодняшний день пустой — его показывают на демо. После загрузки система проверяет правила по итоговому состоянию, и врач сразу видит алерты.

`last_report_days_ago` сдвигает историю назад: пациент перестал вести записи (сценарий 5, правила «нет записей 3 и 5 дней»). Тогда правила проверяются на момент последней записи, а сегодня — только правила о перерывах, как при проверке по расписанию. Иначе у молчащего пациента без отметок приёма сработала бы ещё и «низкая приверженность».

## Формат

```yaml
id: s1                          # совпадает с именем файла
title_ru: "…"
status: draft                   # draft → validated после проверки врачом
author_ru: "врач команды"
patient: { full_name: "Сценарий 1: …", email: scenario1@example.com, sex: male, age: 63 }
anamnesis:                            # раздел «Анамнез» у врача и «Моя история» у пациента
  complaints: "…"                     # жалобы — пересказом, не дословно
  history: "…"                        # история заболевания
  notes: "…"                          # примечания; записаны от имени демо-врача в первый день истории
diagnoses:
  - { icd10: "F41.1", title: "Генерализованное тревожное расстройство",
      source: exam,                   # discharge (выписка) | exam (осмотр) | patient (со слов) | mis (МИС) | other
      source_note: "первичный приём", # какая выписка, чей осмотр; для other — обязательно
      diagnosed_ago: start }          # start — первый день истории; 8m, 2y, 14d — столько назад от сегодня
labs:                                 # анализы: id из kb/labs.yaml, единица — оттуда же
  - { analyte: egfr, value: 51, days_ago: 10, source: lab, source_note: "поликлиника" }
past_medications: ["Пароксетин"]      # до Авиандра, уже отменены
prescribe_aviandr: true               # false — врач назначает на демо
aviandr_dose_mg: null                 # только по инструкции ГРЛС
last_report_days_ago: 1               # 1 — последняя запись вчера; 6 — пациент молчит 6 дней
weeks:                                # неделя 0 — визит и назначение
  - week: 0
    anxiety: 7                        # самочувствие 0–10, одно значение на всю неделю
    mood: 3
    sleep: 4
    gad7: 14                          # сумма; ответы по пунктам раскладываются поровну
    phq9: 9
    phq9_item9: 0                     # пункт 9 отдельно (0–3)
    phq4: 7                           # раз в неделю; остаток суммы — сначала пунктам тревоги (1–2)
    intake_days: 6                    # дней с приёмом из 7
    adverse_events: [{ description: "…", severity: mild, serious: false }]
    messages: ["…"]                   # сообщения пациента в чат
    expected_ru: "что должна показать система"   # для проверки демо, в базу не пишется
expected:
  referral_ru: "…"
```
