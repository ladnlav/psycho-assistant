# Оценка извлечения из историй болезни

Это техметрика №2 кейса: точность и полнота извлечения из историй болезни разных шаблонов.

## Формат набора
- `data/<id>.txt` — синтетическая история болезни. Пишет Савва, нужно 20–30 штук **в разных шаблонах**: разный порядок разделов, детализация, стиль, формат диагнозов и назначений.
- `gold/<id>.json` — эталонная разметка по схеме `app/schemas.py::ExtractionResult`.

Пример: `example_001`. Реальные данные пациентов **не использовать**.

## Запуск
```bash
cd ml
python -m eval.run_eval            # нужен LLM-сервер, см. LLM_BASE_URL / LLM_MODEL в .env
```
Отчёт `eval/runs/<время>/report.json` содержит precision, recall и F1 по каждому полю и среднее время на документ. Эти цифры идут в презентацию.
