# Оценка извлечения из историй болезни

Это техметрика №2 кейса: точность и полнота извлечения из историй болезни разных шаблонов.

## Формат набора
- `data/<id>.txt` — синтетическая история болезни. Пишет Савва, нужно 20–30 штук **в разных шаблонах**: разный порядок разделов, детализация, стиль, формат диагнозов и назначений.
- `gold/<id>.json` — эталонная разметка по схеме `app/schemas.py::ExtractionResult`.

Пример: `example_001` — образец формата, в метрику не входит (`run_eval` берёт только `hist_*`). Реальные данные пациентов **не использовать**.

Диагнозы и сопутствующие с кодом МКБ сравниваются по коду. Без кода — по тексту: совпадение, если слова одной формулировки входят в другую («ГБ 2 ст» = «ГБ 2 ст, контролируемая, риск ССО 4»).

## Набор на 24.10
`hist_002`–`hist_013` — 12 вымышленных историй в разных форматах: направление 057/у, консультации невролога и психиатра, абзац с сокращениями, выписной эпикриз, телемедицина, женская консультация, осмотр на дому, консультативный лист полями. Черновики команды отредактировал Савва: у терапевта и невролога основной диагноз — G90.8, а психиатрический — в «развёрнутом клиническом диагнозе», часто с «?».

**`gold/hist_*.json` — черновик эталона, его проверяет Матвей (M4).** Правила разметки:
- `diagnoses` — психиатрические и неврологические диагнозы, соматические — в `comorbidities`, даже если психиатрический назван «сопутствующим» (hist_005);
- `icd10` — только если код есть в тексте, иначе `null`, и метрика сравнивает текст диагноза;
- препараты — как в тексте: назначенные и рекомендованные — `current`, отменённые — `past`;
- возраст только по дате рождения — `null` (hist_013);
- отрицания («суицидальные мысли отрицает», «АГ отрицает») — не факты и не флаги;
- алкоголь, упомянутый явно, — `substance_use` и без F10 (hist_011).

Открытые вопросы:
1. «ГТР?» / «ГТР???» без кода (hist_003, hist_004, hist_013) сейчас **не** в эталоне: это подозрение, а текст сравнивается точно. Если модель его выдаст, это засчитается как ложное срабатывание. Оставить так или добавить?
2. hist_012: «Расстройство адаптации» и «Самоповреждающее поведение» — в эталоне текстом, без кода.
3. hist_010: основной диагноз в тексте пустой — так задумано, эталон по нему пуст.

## Запуск
```bash
cd ml
python -m eval.run_eval            # нужен LLM-сервер, см. LLM_BASE_URL / LLM_MODEL в .env
```
Отчёт `eval/runs/<время>/report.json` содержит precision, recall и F1 по каждому полю и среднее время на документ. Эти цифры идут в презентацию.
